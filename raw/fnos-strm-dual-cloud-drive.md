## 一、底层机制：什么是 STRM？为什么必须“改名先行”？

### 1. 什么是 STRM？
用人话解释：**STRM 文件就是一个普通的纯文本文件，扩展名是 `.strm`，里面只有一行纯文本，即该视频对应的网盘官方 CDN 直链播放 URL。**

- **传统挂载模式**：NAS 充当中转站把视频从网盘下载到本地内存或缓存盘，再实时推流给电视。不仅吃满 NAS 内存与内网带宽，频繁扫库还会被网盘限速封杀；
- **STRM 直链模式**：
  1. 飞牛影视在本地读取几 KB 的 `.strm` 小文件（耗时仅 1~2 毫秒）；
  2. 获取到直链后，电视端播放器跳过 NAS 中转，直接向 115 或夸克官方 CDN 请求视频切片；
  3. 实测首播响应时间仅 **913ms**，6GB 视频拖拽进度条仅 **518ms**（命中 `HTTP 206 Partial Content`）；
  4. 飞牛影视日常的海报刮削与元数据刷新，全部在本地读写小文件，**对网盘 API 请求量暴降 99%**，物理根除风控。

### 2. 绝对不可颠倒的执行时序
整个影音自动化闭环的时序逻辑极其严密：

```text
1. 片名自动搜盘（pansou 引擎毫秒检索夸克/115分享）
   ↓
2. 智能排假与单文件精准转存（剔除伪视频，仅提取 4K 原生正片）
   ↓
3. 网盘标准化重命名（通过夸克官方 Skill 对齐 TMDB，改名必须先行）
   ↓
4. Webhook 触发 SmartStrm 增量生成 STRM 与字幕
   ↓
5. 本地镜像同步至飞牛影视共享目录（自动修剪死链）
   ↓
6. 飞牛影视本地刮削入库（TMDB 毫秒匹配海报墙）
   ↓
7. 「看完即焚」自动释放（电影看后24h进回收站，白名单资产永久保留）
```

> **核心铁律：改名必须在生成 STRM 之前完成！**
> STRM 记录的是已经固化的网盘文件路径。如果先生成了 STRM，再去网盘重命名，原本生成的 STRM 会**瞬间全量变死链**，导致媒体库全盘报错崩溃。

## 二、从零部署：安装 SmartStrm 与自动转存套件

### 1. 安装 SmartStrm（直链生成引擎）
SmartStrm 是飞牛 NAS 上将网盘路径转化为 STRM 直链的核心服务。

**安装步骤**：
1. 登录飞牛桌面，打开 **应用中心**；
2. 在应用中心搜索栏直接输入 `SmartStrm`（飞牛官方应用中心已直接收录，开箱即用，无需配置任何第三方源）；
3. 点击 **【安装】**；
4. 安装完成后，在浏览器打开控制台：
   ```text
   http://<你的飞牛NAS_IP>:8024
   ```
   首次打开按提示设置管理员账号和密码。

**底层目录分布（持久化说明）**：
- 核心配置文件：`/var/apps/smartstrm/shares/SmartStrm/config/config.yaml`（存储网盘 Token 与任务配置）；
- STRM 临时生成卷：`/var/apps/smartstrm/shares/SmartStrm/strm/<task_name>/`；
- 飞牛共享目录：`/vol1/1000/公共共享/视频/`。

---

### 2. 在飞牛应用中心一键安装「夸克网盘自动转存」（自带 pansou 搜源）
千万不要去命令行手写 Docker Compose！飞牛第三方应用中心早就封装好了开箱即用的套件，直接在界面点一下安装就能完成全部部署。

**安装步骤**：
1. 打开飞牛桌面，进入 **应用中心**；
2. 确保已开启第三方社区源（点击应用中心右上角 **设置** -> **应用源**）；
3. 在应用中心搜索框输入 **`夸克网盘自动转存`**（后台标识为 `quark-auto-save`，应用描述中注明“集成 pansou 版本，实现一键搜索转存”）；
4. 点击 **【安装】**：
   - 飞牛系统会自动在后台完成容器拉取、目录挂载以及伴生搜盘引擎的网络桥接；
   - 搜盘、自动转存、追更整理一条龙全部就绪，无需手动敲命令建目录；
5. 安装完成后，飞牛桌面上会自动生成 **夸克网盘自动转存** 的快捷应用图标。

**访问端点与底层服务**：
- **转存管理控制台**：点击桌面图标直接打开，或浏览器访问 `http://<你的飞牛NAS_IP>:15005`（首次进入根据向导绑定夸克账号）；
- **伴生 pansou 搜盘引擎**：套件已在内部自动拉起并常驻在 `http://<你的飞牛NAS_IP>:8888`，对外直接提供片名检索接口。

## 三、网盘挂载实操：手把手绑定 115 与夸克

### 1. 在 SmartStrm 中挂载 115 网盘（官方开放平台）
1. 浏览器打开 SmartStrm 网页端（`http://<NAS_IP>:8024`）；
2. 点击左侧导航栏 **【存储管理】** -> **【添加存储】**；
3. 参数填写：
   - **存储类型**：选择 `115开放平台 (open115)`；
   - **存储名称**：填写 `115_main`（后续配置任务必须对应）；
   - **速率限制**：填写 `1`（表示请求限制为 1 秒 1 次，平稳防封）；
4. 点击 **获取授权二维码**，界面会弹出 115 官方授权二维码；
5. 打开手机 **115 App**，点击扫一扫完成授权；
6. 授权成功后，状态显示绿色，界面会自动读出当前 VIP 等级（如年费VIP）和剩余容量（如 40TB+）。

---

### 2. 在 SmartStrm 中挂载夸克网盘（TV 直链驱动）
夸克网盘必须使用 TV 协议，因为只有 TV 协议支持 CDN 原画直链输出。

1. 进入 SmartStrm **【存储管理】** -> **【添加存储】**；
2. 参数填写：
   - **存储类型**：选择 `夸克网盘TV (quark_tv)`；
   - **存储名称**：填写 `quark_main`；
   - **模式**：选择 `streaming`（直链串流模式）；
3. 点击 **获取登录二维码**，页面生成夸克登录码；
4. 打开手机 **夸克 App** 扫码授权；
5. **⚠️ 避坑提醒（设备数限制）**：
   夸克官方 TV 接口严格限制最多 2 台 TV 设备同时在线。如果点击获取二维码或绑定时报错 `HTTP 500 设备数超限`，按以下步骤解绑：
   - 打开手机夸克 App -> 右下角【我的】-> 右上角【设置】->【账号与安全】->【登录设备管理】；
   - 找到历史闲置的 TV 或第三方设备，点击 **移除/退出登录**，重新扫码即可秒过。

## 四、关键核心：安装夸克官方 Skill 与洗库改名实战

### 1. 为什么必须安装夸克官方 Skill？
很多玩家尝试过自动转存，但都卡死在这一步：
- **夸克 TV 接口是只读的**：SmartStrm 用的 `quark_tv` 驱动只开放看片流，在服务端硬编码拦截了重命名（一旦发起改名直接报错 `500 夸克网盘TV不支持重命名操作`）；
- **网络资源全带广告乱码**：从分享链接存下来的文件往往长这样：
  `【4K影视资源发布组 www.xxx.com】星球大战.2026.2160p.mkv`
  这种文件名扔给飞牛影视，海报刮削识别率几乎为 0；
- **破局解法**：通过**夸克网盘官方 Skill（`quarkclouddrive`）**的开放平台 API 通道，对网盘下发批量改名与清洗指令，绕过 TV 接口的只读限制。

---

### 2. 官方 Skill 安装与授权步骤
在 NAS 宿主机或主控终端中执行以下命令进行安装：

```bash
# 1. 克隆官方 Skill 仓库到技能目录
git clone https://github.com/openclaw/quarkclouddrive.git ~/.hermes/skills/quarkclouddrive

# 2. 运行自动化安装脚本（自动检测并安装 Node.js 运行时环境与依赖）
cd ~/.hermes/skills/quarkclouddrive
bash scripts/install.sh
```

看到终端输出 `✅ quarkclouddrive CLI 安装完成` 后，验证安装：
```bash
node scripts/quark-drive.cjs --help
```

**账号扫码登录授权**：
在终端执行登录命令：
```bash
node scripts/quark-drive.cjs login
```
终端会输出一个授权链接与二维码。复制链接在浏览器打开，或用夸克 App 扫码确认，完成 Open API 权限打通！

### 3. 官方 Skill 实战：单文件精准提取与规范化改名
拥有了官方 Skill 后，洗库变得极度简单高效。

#### 场景 A：从分享包中单文件提取正片（拒绝假视频与广告）
调用 `saveas` 子命令时，加上 `--fid-list` 参数，只转存正片，跳过捆绑的广告文件：
```bash
# 仅转存正片视频文件，指定转存到网盘中的 /影音/电影/ 目录
node scripts/quark-drive.cjs saveas \
  --share-url "https://pan.quark.cn/s/xxxxxx" \
  --fid-list "正片文件FID" \
  --to-pdir-path "/影音/电影/"
```

#### 场景 B：标准化重命名（对齐 TMDB）
转存完成后，调用改名功能，剔除网站广告，格式化为标准命名：
- **电影标准格式**：`片名 (上映年份).扩展名`
- **电视剧标准格式**：`剧名/Season 01/剧名.S01E01.扩展名`

```bash
# 示例：将带广告的文件规范重命名为 TMDB 标准名称
node scripts/quark-drive.cjs organize \
  --fid "文件FID" \
  --new-name "星球大战：曼达洛人与古古 (2026).mkv"
```

## 五、闭环联动：Webhook 触发、镜像同步与串流探活

### 1. 配置 SmartStrm 增量任务
在 SmartStrm 控制台 **【任务管理】** -> **【添加任务】**：
- **任务名称**：`quark_movies`
- **存储来源**：选择前面配置的 `quark_main`
- **网盘路径**：`/影音/电影`
- **生成参数配置**：
  - 勾选 `增量生成 (incremental)`：只对新增视频生成，不重复扫描；
  - 勾选 `目录时间校验 (dir_time_check)`：按修改时间快速跳过未变动文件；
  - 勾选 `保留本地资产 (keep_local_asset)`：防止误删字幕。

保存后，SmartStrm 会为该任务分配一个专有的 Webhook 触发 URL：
`http://<NAS_IP>:8024/webhook/a7b7c5d390b886e4`

---

### 2. QAS 容器 Webhook 联动配置（避开 127.0.0.1 大坑）
进入 QAS 自动转存控制台（`http://<NAS_IP>:15005`），在对应转存规则的高级设置中填入 Webhook 地址。

> **⚠️ 核心避坑**：
> 绝不能填写 `http://127.0.0.1:8024`！因为 QAS 跑在 Docker 容器内部，`127.0.0.1` 指向的是容器自己，根本连不上宿主机。
> **正确填写**：填写 Docker 宿主网关 IP（如 `http://172.31.0.1:8024/...`）或 NAS 的局域网真实 IP（如 `http://192.168.1.100:8024/...`）。

转存完成后，QAS 会自动向 SmartStrm 发送 POST 请求：
```json
{
  "event": "qas_strm",
  "data": {
    "strmtask": "quark_movies",
    "savepath": "/影音/电影/星球大战：曼达洛人与古古 (2026)"
  }
}
```
SmartStrm 接收到通知后，将在 **1秒内** 在本地生成对应的 `.strm` 文件！

---

### 3. 本地镜像同步至飞牛共享目录
SmartStrm 生成好的小文件保存在其应用私有目录中。我们需要将其镜像到飞牛影视能够读取的公共共享目录。

编写同步命令并配置定时任务：
```bash
# 增量同步镜像，--delete 参数会自动删除网盘中已失效的旧电影死链
python3 /usr/local/bin/smartstrm-fnos-mirror \
  --config /usr/local/apps/@appdata/smartstrm/fnos-mirror.json \
  --delete
```

---

### 4. 终端串流探活验收（必须看到 HTTP 206）
在终端中模拟播放器发起 HTTP Range 分块请求（读取前 1024 字节）：

```bash
curl --noproxy '*' -s -I -r 0-1024 -L "http://127.0.0.1:8024/smartstrm_fid/quark_main/..."
```

**验收回显标准**：
终端必须返回：
```text
HTTP/2 206 Partial Content
Content-Range: bytes 0-1024/26980540120
Cache-Control: public, max-age=...
```
一旦看到 `206 Partial Content`，说明直链串流完全打通，CDN 缓存命中！

---

### 5. 飞牛影视一秒智能识别入库
打开飞牛桌面，启动 **飞牛影视**：
1. 点击 **【添加媒体库】**；
2. 类型选择 **【电影】**（或【电视剧】）；
3. 路径选择刚才同步的本地共享目录（例如 `/vol1/1000/公共共享/视频/电影/SmartStrm_Quark`）；
4. 点击 **【确定】**。

> **飞牛原生优势（零配置识别）**：飞牛影视内置了官方原生的智能元数据识别服务，**完全不需要像 Emby/Jellyfin 那样手动挑选刮削器，更不需要自己费劲去申请配置 TMDB API Key**！只要前面通过夸克官方 Skill 做好了标准化规范命名，飞牛影视在本地毫秒级读取几 KB 的 `.strm` 文件后，会自动精准完成全库海报、演职员表与简介匹配，海报墙瞬间拉满！

## 六、进阶利器：「看完即焚」全自动空间释放与白名单守护

为了彻底摆脱“屯片一时爽，网盘天天满”的困扰，我们在系统中引入了自动清理看门狗。

### 1. 状态判断逻辑 (`trimmedia.db`)
飞牛影视将所有播放记录存储在内置数据库中：
`/usr/local/apps/@appdata/trim.media/database/trimmedia.db`

清理程序只读查询 `item_user_play` 数据表：
- 播放状态：`watched = 1`（已观看完毕）；
- 时间差：`(当前时间戳 - update_time) >= 86,400,000`（看完已满 24 小时）。

### 2. 清理规则与白名单保护机制
1. **🛡️ 白名单永久守护（绝对防误删）**：
   - 凡路径或标题包含 `动画片`、`动画`、`纪录片`、`儿童`、`经典合集`（如《汪汪队》《小汽车欧力》《皮克斯动画》），**系统物理跳过，永久保留，绝不删除**；
2. **🎬 电影处理**：
   - 普通电影标记已看满 24 小时，自动调用网盘回收站接口删除原片，并移除本地 STRM 文件；
3. **📺 电视剧处理**：
   - 整部剧集 **100% 全部集数均标记已看** 且最后一集看完满 24 小时，才触发整季清理（追剧中途绝不误删）；
4. **安全可逆**：
   - 115 与夸克网盘均调用官方回收站接口（文件保留 30 天），误标记可在手机网盘 App 中一键撤回恢复。

### 3. 配置凌晨自治 Cron
在宿主机配置系统定时任务：
```bash
crontab -e
```
添加以下任务：
```cron
# 每日凌晨 00:05 自动执行清理巡检并发送汇总通知
5 0 * * * python3 /root/scripts/xue_fnos_watched_cleaner.py --send-report
```

## 七、量化实测与对比总结

整套闭环落地运行后，实际体验提升极其明显：

| 评估指标 | 传统 WebDAV 挂载 | 本地机械硬盘下载 | STRM + 看完即焚闭环 |
| :--- | :--- | :--- | :--- |
| **本地磁盘占用** | 0 GB（但易吃满系统缓存） | 30GB ~ 80GB / 部 | **仅 4 KB / 部** |
| **首播响应速度** | 3s ~ 10s（易卡顿） | 秒开（需提前几小时下载） | **约 913ms（极速秒播）** |
| **进度条拖拽** | 频繁转圈缓冲 | 秒响应 | **约 518ms（丝滑跳转）** |
| **网盘风控概率** | 极高（全库扫描被封） | 极高（频繁大流量拉取） | **极低（API 请求下降 99%）** |
| **空间维护成本** | 需人工定期排查删除 | 硬盘塞满需持续花钱扩容 | **看完 24 小时自动释放** |

不仅让电视端畅享原画杜比视界，更让 NAS 彻底告别了硬盘扩容与网盘爆满的焦虑。

## 八、这套方案适合谁？

**适合谁**：
- 家里 NAS 盘位紧张、不想买昂贵大容量机械硬盘的影音爱好者；
- 拥有 115 VIP 或夸克 VIP，希望将网盘直接化身原生海报墙的用户；
- 痛恨 WebDAV 扫盘被封号、追求搜源、改名、追更、入库到看完自动释放全流程自动化的极客玩家。

**不适合谁**：
- 家庭宽带下行低于 100Mbps 且无网盘 VIP 会员的用户（4K 原画直链需要稳定的下行带宽）；
- 追求 100% 离线、断网也要看本地原盘的发烧友。
